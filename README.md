# SLD-ML Benchmark v1

**Milling stability lobe diagrams for machine-learning surrogates: coarse-to-fine pairs, exact spectral-radius labels, and a standard evaluation protocol.**

Version 1.0 · License: CC-BY-4.0 · DOI: `10.5281/zenodo.`(TBD after upload)

## What this is

A public benchmark dataset for machine-learning surrogates that predict
milling stability lobe diagrams (SLDs). It provides, for 90 parameter sets
of the standard two-DOF milling model:

- paired coarse (16x10, 32x20) and fine (128x80) spectral-radius fields
  generated by a first-order semi-discretization (SDM) solver;
- exact Floquet spectral radii (`rho`) per grid point, not only binary
  masks;
- a second fine label at m=160 on the validation/test splits (20 cases) to
  quantify label discretization uncertainty;
- a 70/10/10 train/validation/test split whose test cases are
  extrapolations (low immersion, low damping, low natural frequency);
- a standard evaluation protocol (F1, false-stable fraction, boundary
  distance, per-method wall-clock time, difficulty layers) with a
  command-line scorer;
- classical baselines (analytic ZOA boundary, bilinear/nearest upsampling)
  and two reference U-Net models, all precomputed in `results/`.

## Key numbers (10 test cases)

| Method | All-10 F1 | Non-trivial-7 F1 | False-stable (all-10) |
| --- | --- | --- | --- |
| ZOA analytic | **0.965** | **0.952** | **0.007** |
| bilinear32 | 0.931 | 0.902 | 0.045 |
| U-Net (3 seeds) | 0.905 | 0.865 | 0.107 |
| bilinear16 | 0.870 | 0.814 | 0.101 |
| nearest16 | 0.854 | 0.791 | 0.152 |
| coarse-ZOA + bilinear | 0.855 | 0.793 | 0.146 |
| ZOA-conditioned U-Net + monotone projection | 0.932 +/- 0.001 | 0.905 | 0.064 |

The analytic ZOA boundary remains the strongest and safest baseline in the
studied parameter box; the benchmark's purpose is to calibrate where each
method can be trusted. All numbers are reproducible from the included
code and `results/` JSON files.

## Data format

Each file `data/rho/case_<idx>_<grid>_m<m>.npz` contains:

- `rho`: flat float64 array, row-major over (depth x speed) = 128x80
  (fine), 32x20 (c32) or 16x10 (c16); spectral radius of the one-period
  transition matrix (rho < 1 stable);
- `n_rpms`: speed grid (4000-16000 rpm);
- `a_p_mm`: axial-depth grid (0.05-1.5 mm);
- `case`: parameter dictionary; `m`: discretization count.

## Evaluation protocol

For every test case, evaluate binary stable masks against the fine m=80
label and report: pixel F1 / precision / recall, false-stable fraction,
mean boundary distance, per-map wall-clock time, and the difficulty layer
(trivial >= 0.99, medium 0.5-0.99, hard < 0.5 stable-pixel fraction).
Report both headlines (all 10 cases and the 7 non-trivial cases). Use the
included scorer:

```bash
python code/benchmark_eval_cli.py --pred <pred.npz> --case 6
# pred: npz with key "mask" (binary) or "rho" (thresholded at --t)
```

## Reproduction

See `docs/DATASET_DESCRIPTOR.md` for the full generation and audit
pipeline. Minimal audit re-run:

```bash
python code/benchmark_spotcheck_cpu.py   # labels vs audited CPU solver
python code/benchmark_zoa_scan.py        # ZOA head-to-head over 90 cases
```

## Provenance and honesty statement

This dataset was generated and curated with heavy AI assistance (a Codex
research agent), and the entire pipeline was subjected to six independent
adversarial reviews; every headline number in this release was recomputed
by reviewers and matches the stored JSON. The solver itself was audited
against Gauss quadrature, an exact characteristic equation, and two
independent time-domain integrators. Known limitations are documented in
the data card; no experimental cutting data is included in v1.
